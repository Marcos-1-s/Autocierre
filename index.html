Etiqueta br

La etiqueta br sirve para hacer un salto de línea dentro de un texto. Por ejemplo, esta es la primera línea.
Y esta es la segunda línea.

Etiqueta hr

La etiqueta hr sirve para separar temas o bloques de contenido mediante una línea horizontal.

Este texto aparece debajo de la línea horizontal.

Etiqueta img

La etiqueta img sirve para mostrar imágenes. El atributo alt proporciona un texto alternativo que describe la imagen.

Etiqueta input

La etiqueta input permite al usuario introducir información en un formulario.

Acepto las condiciones

Etiqueta link

La etiqueta link permite enlazar recursos externos, como una hoja de estilos CSS. En esta página se utiliza para aplicar colores y estilos al contenido.

Etiqueta meta

Las etiquetas meta proporcionan información sobre la página. charset indica la codificación de caracteres, viewport configura la visualización en distintos dispositivos y description describe el contenido de la página.

Etiqueta col

La etiqueta col permite aplicar estilos a las columnas de una tabla mediante colgroup.

Etiqueta Función
br Salto de línea
hr Línea horizontal

Etiqueta embed

La etiqueta embed permite incrustar recursos externos, como una imagen SVG, dentro de una página web.

Etiqueta param

La etiqueta param se utilizaba para establecer parámetros de un objeto incrustado. Actualmente está obsoleta y los navegadores modernos la ignoran, por lo que no produce un efecto visible en este ejemplo.

Etiqueta source

La etiqueta source permite indicar el archivo multimedia que utilizará un elemento audio o video. Se pueden proporcionar varias fuentes para mejorar la compatibilidad.

Etiqueta wbr

La etiqueta wbr indica un punto donde el navegador puede dividir una palabra larga si es necesario.
